# Notas del curso

## Que es Git

Git es un sistema de control de versiones: guarda el historial de cambios
de un proyecto y permite volver atras o trabajar en paralelo.

## Que es GitHub

GitHub es un servicio en la nube que aloja repositorios Git y anade
herramientas de colaboracion (issues, pull requests, etc.).

## Conceptos clave

- **Repositorio**: carpeta del proyecto con su historial.
- **Commit**: fotografia de los cambios en un momento dado.
- **Rama (branch)**: linea de trabajo independiente.
- **Remoto (origin)**: copia del repositorio en GitHub.
