# Mi primer proyecto con Git

Proyecto de ejemplo para aprender a usar **Git** y **GitHub** desde cero.

## Contenido

- `index.html`: estructura de la pagina.
- `css/estilos.css`: estilos.
- `js/app.js`: logica de la lista de tareas.
- `docs/notas.md`: apuntes del curso.

## Como usarlo

1. Abre `index.html` en el navegador.
2. Pulsa el boton "Anadir tarea".
